# Committed compute-unit baselines for the payment paths (spec §10, gate per §11).
#
# This file is the single source of these numbers. `budget.rs` embeds it with
# `include_str!` and asserts against it; nothing else should restate a figure from
# here. The previous arrangement kept the baselines as consts in `budget.rs` and a
# second copy in the spec §10 table, and both drifted ~820 CU behind the build
# without anything failing — the +10% band absorbed it silently, which is the exact
# failure a baseline is supposed to make loud.
#
# Refresh with `scripts/cu-baseline.sh`, which re-measures and rewrites this file.
# Do not hand-edit a number to make a red test green: a change here is a claim that
# the new cost is intended, and the diff is where that claim gets reviewed.
#
# Columns: key  baseline  spec_gate  label
#
# `spec_gate` is the design ceiling from spec §10, and takes three spellings:
#   <n>        this path fits that gate and must keep fitting it
#   over:<n>   this path is over its gate — a recorded exemption, asserted in
#              reverse so a path that starts fitting again cannot leave the
#              exemption to rot. Never introduce one to make a test pass; it
#              needs a spec amendment, the way §10.1 documents the 35k SOL gate.
#   none       no spec section has ever committed a number for this path
#
# `baseline` is what this build actually costs. §11 fails at +10% over it, which
# catches a change long before it reaches the design gate.

execute_payment_spl_allowlist     43765  45000  execute_payment (SPL Token, allowlist, no ATA creation)
execute_payment_spl_any           41572  45000  execute_payment (SPL Token, any destination, no ATA creation)
execute_payment_sol               32150  35000  execute_payment_sol
# No spec number was ever committed for the ADR-014 CPI path, and this measurement
# still derives the native PDAs with `find_program_address` rather than taking
# caller-supplied bumps (the gap ADR-014's Consequences section names). That blocks a
# *design gate*, not a *baseline*: the +10% band below catches a regression either
# way, and it replaces the 150k sanity ceiling this path used to sit under — a
# ceiling 2.2x the real cost would not have caught a doubling.
